## 参数与质量指标

原厂配置的滤波器索引缺少 Hz 映射。每会话每通道用完整两秒窗的 Hann 周期图，逐频点取跨窗中位数。低于 20 Hz 或高于 min(450 Hz, 0.45 × 实测采样率) 的功率各自超过总功率 5% 时才加入相应四阶 Butterworth 高通或低通。工频中心 ±1 Hz 的平均谱密度比两侧 3–8 Hz 的参考频带高至少 8 dB，且该窄带至少占总功率 1%，才增加 50 Hz 陷波（Q=30）。这些阈值是本分析的选参规则，不能反推硬件通带。中位数去偏后进行双向零相位滤波，全波整流，用二阶 5 Hz 双向低通提取非负包络。每次动作约 3 秒，另算 75 ms 滑动 RMS 核对活动时程。

quality.csv 保存整段的样本缺失、24 位 ADC 触轨、最长恒值段及滤波决策。features.csv 每行是一个通道的一次提示，含主机边界、排除原因、平均/峰值包络、峰时、RMS、积分肌电和波形核对指标。动作及其滤波上下文缺失、触轨、连续恒值 ≥50 ms，或相邻差分超过 12 个稳健标准差的比例 >1%，均排除。此处的平直和尖峰规则只能筛查部分电极接触异常。缺失保留为空。无 MVC 记录，幅值保留 mV；图 3 的颜色是同一人同一通道各方向中位数相对四方向均值的 log2 比值。

## 统计与图形

profiles.csv.gz 存放有效试次的 101 点时间归一包络；纵轴仍为 mV。repeatability.csv 给出同方向有效重复数、平均包络幅值的跨试次 CV 与试次波形两两 Pearson 相关的中位数。selectivity.csv 比较四个方向的试次中位幅值，统计同轮中首选方向单独胜出的次数。四方向各至少有三次有效重复才参与筛选。候选须同时满足首选/次选 ≥1.25、至少三轮胜出、首选方向 CV ≤0.30 与相关中位数 ≥0.50。固定的方向顺序可能混入顺序效应。指标反映提示锁定的重复性，单人候选需独立数据验证。
